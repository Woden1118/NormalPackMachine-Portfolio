# NormalPack Studio · 图标与启动页

- `assets/NormalPack.ico`：独立 Windows 图标，包含 16 / 24 / 32 / 48 / 64 / 128 / 256 像素。
- `assets/NormalPack-icon-preview.svg`：公开仓库展示用图标预览（矢量绘制）。
- `examples/WpfSimulator/Assets/NormalPack.ico`：模拟器的应用资源。
- `examples/WpfSimulator/SplashWindow.xaml`：模拟器启动画面，约 1.5 秒后进入主窗口。

所有界面、图标和模拟代码仅作作品集展示，不含原私有项目的设备代码、客户数据或商业授权资料。
