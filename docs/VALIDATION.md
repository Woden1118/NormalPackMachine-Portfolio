# 作品集验证记录与操作清单

**状态：尚未完成 Windows / Visual Studio 2022 实际编译或运行。**

## 独立模拟器的验证方法

- [ ] Windows 10 / 11 x64 安装 Visual Studio 2022 和 .NET 桌面开发工作负载。
- [ ] 安装 .NET Framework 4.8 Developer Pack。
- [ ] 打开 `examples/WpfSimulator/WpfSimulator.csproj`，Debug / Any CPU 编译。
- [ ] 确认启动窗口约 1.5 秒后进入主页面，EXE 图标与窗口图标正确。
- [ ] 点击“启动模拟”，检测计数递增，且 OK + NG 等于检测总数。
- [ ] 点击“停止模拟”，不再产生新的检测，窗口保持响应。
- [ ] 连续启动/停止 10 次，确认不会重复启动循环或出现跨线程异常。
- [ ] 运行过程中关闭主窗口，不遗留后台进程。

## 不在公开仓库中进行的生产验证

真实设备的相机触发、PLC 握手、NG 互锁、MES 断线、账号权限、急停和现场安全试验必须由有授权的专业人员在合适环境执行。本作品集并不具备这些生产功能。
